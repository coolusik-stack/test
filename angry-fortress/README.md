# 도토리깡

**작아도 깡 하나는 숲에서 제일!** 겨울 도토리를 걸고 두 다람쥐 깡단이 맞붙는 턴제 새총 포격 대결입니다. 이긴 쪽이 도토리를 몽땅 차지합니다. 포트리스식 대결 구도에 새총 물리 퍼즐의 손맛을 합친 모바일 우선 HTML5 게임으로, 빌드 과정 없이 정적 파일로 바로 실행됩니다.

핵심은 **친구와 각자 폰으로 1:1**입니다. 방을 만들고 4자리 코드를 알려주면 친구가 자기 폰에서 들어와 번갈아 쏘며 싸웁니다.

숲은 **구름 위에 떠 있는 섬**입니다. 옛 포트리스처럼 상대 발밑의 땅을 파내 구름 아래로 떨어뜨리면 체력과 상관없이 즉시 이깁니다. 체력에서 밀려도 한 번에 뒤집을 수 있습니다.

- **참나무단** — 주황 다람쥐 대장 '토리'
- **솔숲단** — 회색 청설모 대장 '솔이'
- **깡단 꼬맹이들** — 대장마다 둘씩 따라다니는 꼬마 다람쥐
  - 깡이: 대장 모자 위에 앉아 다닙니다. 도토리 헬멧이 너무 커서 한쪽 눈을 가리고, 큰 앞니가 하나 있어요. 늘 주먹을 불끈 쥐고 있습니다.
  - 냠이: 수레 뒤를 쫓아다닙니다. 자기보다 큰 꼬리에 볼이 빵빵하고, 늘 도토리를 쥐고 있어요.
  - 쏠 때마다 "깡!" 외치고, 맞히면 춤추고, 맞으면 데굴데굴 굴렀다가 벌떡 일어나 경례하며 "끄떡없어!". 벼랑 끝에서는 아래를 내려다보며 침을 꼴깍, 수레가 떨어질 땐 매달려 비명. 져도 잠깐 울고 나서 알통을 보이며 "다음엔 이긴다!" 언제나 씩씩합니다.

## 실행

```bash
cd angry-fortress
python3 -m http.server 8080
# 휴대폰/브라우저에서 http://<내 IP>:8080 접속
```

**iOS 앱(TestFlight)**: `npm install && npm run ios && npm run ios:open`으로 Xcode 프로젝트를 엽니다. 자세한 절차는 [IOS.md](IOS.md)에 있습니다. 진동(햅틱)은 iPhone 앱에서만 됩니다(iPhone 사파리는 진동 미지원).

ES 모듈을 쓰므로 `file://`로 직접 열면 동작하지 않습니다. 정적 호스팅(Cloudflare Pages, Firebase Hosting 등)에 폴더째 올리면 되고, 홈 화면에 추가하면 전체 화면 PWA로 오프라인에서도 실행됩니다.

## 플레이

- **모드**
  - **친구와 대결 (각자 폰으로 1:1)**: 방장이 '방 만들기'로 4자리 코드를 받고 '알려주기'로 공유, 친구는 '방 들어가기'에서 코드 입력. 방장이 전장·바람·턴 제한을 고르고 시작. 대결 중 이모티콘(😆😤😱👍🔥😭), 끝나면 '한 판 더'로 재대결(진 쪽이 먼저 쏨). 한쪽이 새로고침하거나 잠깐 끊겨도 타이틀의 '방 ○○○○로 돌아가기'로 이어서 할 수 있음. 링크에 `?join=코드`를 붙이면 바로 참가 화면이 열림
  - **번갈아 대결**: 폰 하나로 둘이 번갈아
  - **CPU 연습**: 쉬움/보통/어려움
- **조작**: 새총 근처를 누른 채 뒤로 당겼다 놓기. 두 손가락으로 확대/축소, 한 손가락 드래그로 화면 이동, 두 번 탭하면 내 위치로 복귀. 이동 게이지는 매 턴 가득 차고 간 거리만큼 줄어듦(오르막은 더 듦, 평지로 약 8m)
- **견과 탄환**: 날아가는 중 화면을 터치하면 능력 발동
  - 도토리(무제한): 묵직한 기본탄, 땅에 부딪히면 구덩이
  - 잣(3발): 초고속 돌진, 나뭇가지에 강함
  - 땅콩(3발): 껍질이 갈라지며 알맹이 셋으로 분열, 각각 작은 폭발, 고드름에 강함
  - 밤송이(2발): 가시 대폭발로 지형과 요새를 크게 파괴
  - 호두(2발): 공중에서 멈췄다가 수직으로 내리꽂힘. 땅에 박히면 2.8m를 뚫고 들어가 속에서 터짐(땅파기 전용). 대장이나 요새에 맞으면 그 자리에서 쾅
- **요새 블록**: 나뭇가지, 조약돌, 나뭇잎 뭉치(잘 부서짐), 통나무(무겁고 굴러감), 벌집(깨지면 벌떼가 주변을 쏨), 버섯(통통 튕김). 요새 설계도 6종에 재료가 랜덤으로 바뀌며, 양쪽은 항상 같은 모양(좌우 대칭)
- **숲의 장애물** (매 판 랜덤, 좌우 대칭 배치)
  - 도토리나무: 수관을 맞히면 흔들리며 열매가 떨어져 아래를 때림, 견과가 느려짐. 줄기를 부수거나 발밑 땅을 파내면 통째로 쓰러져 주변을 덮침(그루터기가 남음)
  - 나무에 매달린 벌집: 나무를 맞히면 줄이 끊어져 떨어지고, 땅에 닿으면 터져 벌떼가 쏟아짐
  - 거미줄: 견과를 잠깐 붙잡았다 떨어뜨림. 붙잡힌 동안에도 능력 사용 가능
  - 민들레: 맞히면 씨앗이 날리며 바람 방향이 즉시 뒤집힘
  - 도토리 바구니: 깨면 쏜 쪽이 특수 견과 +1
- **추락** (이 게임의 핵심)
  - 모든 맵은 끝없는 구름 바다 위에 뜬 섬. 섬은 가운데가 두껍고 끝으로 갈수록 얇아지는 거꾸로 선 산 모양이고, 처음 대장 발밑은 약 3.6m
  - 구름 아래로 떨어지면 체력과 상관없이 즉시 K.O. 떨어지는 동안 슬로모션으로 따라가며 "추락 K.O.!"
  - 발밑 땅이 2.1m보다 얇아지면 금이 가고 섬 밑으로 흙부스러기가 떨어짐. 이미 1.5m보다 얇아진 땅은 근처에 다시 뭔가 맞는 순간 "우지끈!" 무너짐(그래서 떨어지기 전에 항상 금 간 모습을 한 턴은 보게 됨)
  - 수레는 벼랑이나 깊은 낭떠러지 앞에서 스스로 멈춤(맞아서 밀려나는 건 못 막음). 소나기 때는 더 멀리 밀려 벼랑 끝이 더 위험
  - 오래 끌면 18턴부터 구름이 차오름
- **맵** (열두 맵 모두 손으로 설계한 고정 맵. 맵마다 아이디어 하나, 좌우가 다른 비대칭: 두 집의 높이와 땅이 다르고 한쪽 장점은 다른 값으로 치름. 누가 어느 집을 갖는지는 판마다 뽑음(원정은 단계마다 정해짐). 가운데에 보여 주기용 나무·바구니 없음. 봄·여름·가을·겨울 세 개씩, 계절마다 하늘·풀·나무·날리는 것이 다르고 맵 고르는 화면에 계절 표시. 자세한 설계 원칙과 맵별 설계표는 [MAPS.md](MAPS.md))
  - 도토리 숲 (봄) "언덕 하나": 왼쪽은 낮은 풀밭과 🌰 도토리 명당, 오른쪽은 1.4m 높은 언덕 어깨(땅이 얇음). 가운데보다 오른쪽에 둥근 언덕, 꼭대기 🔭 전망대
  - 벚꽃 분지 (봄) "내려갈까": 분지 바닥의 🌰 벚꽃 명당. 왼쪽은 3m 높고 가파른 가장자리(나무와 가깝지만 올라오기 느리고 가장자리가 얇음), 오른쪽은 낮고 완만한 가장자리와 🔭 분지 전망대
  - 두더지 굴 산 (봄) "뚫고 갈까, 넘어갈까": 가운데 왼쪽의 가파른 산. 왼쪽 집 앞에서 산 밑으로 🛡️ 두더지 굴이 뚫려 오른쪽 테라스까지 비탈로 올라감. 왼쪽은 낮지만 굴과 🍄 꼭대기 트램펄린(🔭 산꼭대기)이 가깝고, 오른쪽은 3.4m 높은 테라스와 🌰 벚나무 명당
  - 해바라기 비탈 (여름) "기운 섬": 왼쪽 위에서 오른쪽 아래로 기운 해바라기 비탈, 숨을 곳 없음. 왼쪽은 4.6m 높은 끝(내리쏘기, 끝이 얇아 구름 위로 튀어나옴), 오른쪽은 낮고 두꺼운 끝과 🌰 느티나무 그늘
  - 반딧불 징검다리 (여름 밤) "돌섬 건너기": 다섯 개의 떠 있는 돌. 🍄 트램펄린으로 돌에서 돌로. 왼쪽 큰 돌 → 🔭 높은 작은 돌 → 🌰 반딧불 명당 돌 → 집, 오른쪽(2.2m 높은 작은 돌) → 낮은 돌 → 같은 명당 돌 → 집
  - 무지개 하늘다리 (여름) "하늘의 천장": 가운데 하늘에 무지개색 돌다리가 떠 있어 편한 높은 포물선을 막음. 밑으로 쏘거나 아주 높이. 🍄 트램펄린으로 다리 꼭대기 🔭 전망대에 올라감. 왼쪽은 2.2m 높은 언덕, 오른쪽은 낮은 들판과 🌰 여름 그늘
  - 단풍 협곡 (가을) "끊기는 다리": 끝없는 협곡 위 얇은 🌉 흙다리 하나가 왼쪽 높은 벼랑에서 오른쪽 낮은 벼랑으로 기울어 이어짐. 왼쪽은 🔭 벼랑 전망대, 오른쪽은 다리 앞 🌰 단풍 명당. 다리는 2m가 안 되게 얇아 근처에 맞으면 무너지고, 한 번 끊기면 다시 못 건넘
  - 은행나무 참호 (가을) "언덕 뒤에서": 두 집이 각자 언덕 뒤에 숨은 참호, 가운데 골짜기는 비어 있음. 왼쪽은 깊은 참호와 높은 언덕(직사가 안 들어오지만 나도 넘겨 쏴야 함), 언덕 위 🔭. 오른쪽은 1.6m 높은 집과 낮은 언덕 위 🌰 은행 명당(드러남)
  - 소나무 절벽 (가을) "절벽": 6m 절벽. 왼쪽은 고원(내려갈 길 없음, 벼랑 끝 🔭은 얇음), 오른쪽은 두꺼운 저지대와 절벽 밑 🌰 소나무 명당, 고원으로 올라가는 🍄 트램펄린
  - 살얼음 두 섬 (겨울) "건널 수 없음": 구름 틈을 사이에 둔 두 섬. 왼쪽은 4.4m 높고 작고 얇은 섬(벼랑 끝 🔭), 오른쪽은 크고 낮은 섬과 🌰 눈꽃 명당. 오직 쏘기와 파내기
  - 이글루 눈처마 (겨울) "처마와 이글루": 왼쪽은 4m 높은 눈 선반과 눈벽돌 처마(처마 끝 🔭, 얇아서 먼저 무너짐, 밑에 빈 굴), 오른쪽은 낮은 눈밭과 지나갈 수 있는 🛡️ 이글루(눈벽돌 지붕)
  - 오로라 호수 (겨울 밤) "얇은 얼음": 가운데 1.3m 두께로 언 호수, 맞으면 구멍이 나 구름으로 떨어짐. 왼쪽은 넓고 낮은 호숫가와 🌰 눈꽃 명당, 오른쪽은 3.4m 높고 좁은 호숫가(얇음). 하늘에 오로라
- **명당** (자리에 표지판과 빛나는 점선이 있고 들어서면 설명이 뜸. 아이콘이 같으면 효과도 같고, 맵마다 이름과 모양만 다름)
  - 🛡️ 지붕(두더지 굴, 이글루): 머리 위의 흙·바위가 위에서 떨어지는 공격을 막고, 폭발도 흙을 사이에 두면 피해·밀림이 35%로 줄어듦. 대신 낮게 쏜 것은 들어오고, 지붕이 뚫리면 그냥 구멍(호두로 뚫으면 안에서 터짐)
  - 🔭 전망대: 조준선이 두 배로 길어짐(CPU는 조준 오차가 줄어듦). 가릴 것이 없음
  - 🌰 명당: 나무 밑. 내 차례가 이곳에서 시작되면 특수 견과 +1(종류별 최대 4발). 머리 위 나무가 내 높은 샷을 가리고, 나무를 맞으면 열매가 떨어짐
  - 🍄 버섯 트램펄린: 올라타면 정해진 섬으로 슝(이동 게이지 40 사용, 착지 피해 없음, 나는 동안 턴 시간 멈춤)
  - 🌉 흙다리: 건너편으로 가는 유일한 길. 얇아서 근처에 맞으면 무너짐
  - 흙 속에 숨으면(지붕 아래가 아니어도) 폭발이 흙을 지나며 약해짐
- **숲 예보** (5턴마다 두 턴, 한 턴 전에 예고): 돌풍(바람 2배), 소나기(맞으면 수레가 멀리 밀림), 도토리 비(쏠 때마다 하늘에서 도토리가 쏟아짐), 멧돼지 돌진(섬 사이를 뛰어넘으며 전장을 가로질러 블록과 대장을 들이받음. 벼랑 끝에 서 있으면 떨어질 수도)
- **보급 낙하산**: 3턴부터 6턴마다 나뭇잎 낙하산 바구니가 가운데로 내려옴(한 턴에 조금씩). 먼저 맞힌 쪽이 체력 +20 또는 밤송이·호두를 받음(바구니 앞 그림으로 미리 보임)
- **화면: 조용할 때와 터질 때** (앵그리버드처럼): 배경(떠 있는 섬 2층, 하늘색으로 흐리게, 움직이지 않음)·빛줄기·구름·떠다니는 꽃잎과 눈·땅 장식·폭포는 조용하고 연하게, 수레·지형·조준선만 또렷하게. 명당 바닥 점선은 내 차례에 가까운 자리만, 깡단 말풍선은 조준 중엔 없고 한 턴에 하나·20초 간격(추락·승패만 예외). 빗나가면 '쿵', 크게 맞으면 흔들림과 잠깐 느려짐, K.O.와 추락만 슬로모션. 자세한 기준은 [MAPS.md](MAPS.md) 4장
- **배경 음악**: 계절마다 다른 배틀 곡(봄 G장조 우쿨렐레·마림바, 여름 칼립소 스틸팬, 가을 아코디언, 겨울 첼레스타·썰매 방울). 조준 중엔 조용히(멜로디와 베이스만), 쏘면 드럼이 들어오고, 크게 맞히거나 K.O.·추락하면 심벌과 함께 전부 터짐
- **아슬아슬한 순간**: 끝낼 수도 있는 한 방이 상대에게 다가가면 슬로모션·줌인·심장박동 진동, 1.7m 안으로 빗나가면 "아깝다!", 체력 30 이하인데 도토리가 날아오면 화면 가장자리가 붉게 두근거림
- **3판 2선승** (설정에서 단판 선택 가능): 진 쪽이 다음 전장을 고르고 먼저 쏨, 매치 포인트·결승 판 알림
- **규칙**: 체력 100. 직격, 폭발, 떨어지는 블록, 높은 곳에서 떨어져 부딪히는 것이 피해를 주고, 구름 아래로 떨어지면 즉시 패배. 매 턴 바람이 바뀌고, 18턴이 지나면 매 턴 구름이 1.2m씩 차오릅니다.
- **CPU**: 쏘기 전에 갈 수 있는 자리들을 살펴 발밑 두께·벼랑 거리·명당 효과·그 자리에서 노릴 수 있는 최선의 한 방을 따져 옮겨 감(트램펄린도 탐). 피해뿐 아니라 상대 발밑의 땅을 얼마나 파내는지도 계산. 체력에서 밀릴수록 땅을 노리고, 한 방에 떨어뜨릴 수 있으면 그쪽을 고름
- **진동(햅틱)**: 새총을 당길 때 톱니처럼 딸깍, 발사 세기만큼 '퉁', 맞힌 피해만큼 '쿵'(치명타는 두 번), 맞으면 둔탁한 '퍽', 폭발·나무 쓰러짐은 울리는 진동, 호두가 땅을 뚫을 때 '드르륵', 추락할 때 가라앉는 진동, 발밑이 위험하거나 벼랑에서 멈출 때 '톡톡', K.O.·승리·패배 패턴. iPhone 앱은 Core Haptics, 안드로이드 브라우저는 기본 진동
- **데스크톱**: ←/→ 이동, 1~5 탄환 선택, Space 능력, Esc 일시정지, 마우스 휠 확대
- **깡단 원정** (타이틀의 '깡단 원정'): 봄 → 여름 → 가을 → 겨울, 계절마다 3단계, 12단계가 모두 다른 맵(봄: 도토리 숲·벚꽃 분지·두더지 굴 산 / 여름: 해바라기 들판·반딧불 밤숲·무지개 바위다리 / 가을: 단풍 협곡·은행나무 쌍봉·소나무 언덕 / 겨울: 살얼음 벼랑·이글루 마을·오로라 빙벽), 순서대로 열림. 단계마다 상대 이름·옷차림·바람·CPU 실력이 다르고(봄은 쉬움, 가을부터 어려움) 별 3개(이기기 / 체력 50 이상 / 단계 도전: 추락 K.O., 도토리만, 체력 80, 8번 안에, 4번 명중). 마지막은 오로라 빙벽의 왕관 쓴 '솔숲단 큰대장 솔왕'. 예전 원정(맵 넷 × 3단계)에서 모은 별은 같은 순서의 단계로 그대로 옮겨짐. 자유 연습(설정 골라 CPU와)은 원정 화면 아래에
- **깡단 옷장**: 별로 여는 모자(도토리·나뭇잎·버섯·밀짚·솔방울 투구·황금 왕관), 수레(나무·빨강·하늘·풀잎·황금), 발사 자국(하얀 점·나뭇잎·별가루·하트). 후원 팩 전용 3종(리본·산딸기 수레·무지개). 친구 대결에서는 서로의 옷차림이 보임(그림만, 대결 결과와는 무관)
- **결과 카드**: 결과 화면의 공유 버튼. 이긴 대장(옷차림 그대로)·제목·명중/피해/체력·맵·별을 담은 그림을 공유 시트로 보냄(앱은 사진 저장도 가능)
- **깡단 후원 팩** (앱 전용 인앱 구매, 비소모성): 깡단 리본·산딸기 수레·무지개 발사 자국. 깡단 옷장 아래 카드에서 사고, 같은 곳과 설정에서 '구매 복원'. 앱을 켤 때 스토어의 구매 기록을 조용히 다시 읽어 다른 폰이나 다시 설치한 폰에서도 열림(비밀번호를 묻는 동기화는 '구매 복원'을 누를 때만). 웹판에는 상점이 없음
- **안드로이드**: `npm run android`(웹 빌드 + Android 프로젝트 동기화) 후 Android Studio로 열거나, push마다 GitHub Actions의 **Android**가 테스트용 APK를 만듦. 뒤로 가기 버튼은 화면 단계를 하나씩 되돌리고 타이틀에서만 앱을 닫음
- **1분 연습 한 판**: 처음 켜면 타이틀에 뜨는 튜토리얼(도움말에서 다시 할 수 있음). 바람·숲 예보 없는 도토리 숲에서 일부러 빗맞히는 연습 상대와 붙고, 말풍선과 손가락이 당기기 → 놓기 → 이동 → 호두 고르기 → 날아가는 중 톡 → 땅 파서 떨어뜨리기를 하나씩, 직접 해 볼 때까지 기다리며 안내
- **화질 자동 조절**: 대결 중 초당 42프레임을 2번 연속 못 넘기면 화면 해상도를 한 단계 낮춤(배율 2 → 1.6 → 1.3 → 1). 고른 단계는 기억하고, 다음 실행은 한 단계 선명하게 시작해 다시 맞춤. 주소에 `?hq=1`을 붙이면 끔(스토어 스크린샷용)

## 출시와 자동화

출시 일정, 매주 할 일, 당신이 한 번만 해 주면 되는 설정은 [LAUNCH.md](LAUNCH.md)에 있습니다.

- `npm test`: 자동 테스트 12가지(켜짐·내장 글꼴, 메뉴~결과 흐름, 연습 한 판, 원정·옷장, 후원 팩, 모든 맵 양쪽 집에서 명당 돌기, 양쪽 출발점 사격, 두 폰 동기화, 친구 대결 로비, 중계 서버, CPU 한 판, 속도). push마다 GitHub Actions에서도 돕니다.
- `npm run maps:sheet`: 열두 맵을 한 장에 모아 실루엣 비교(`tests/output/maps/sheet.png`)
- `npm run preflight`: 출시 전 점검(스토어 글자 수·상표 키워드·아이콘 투명도·버전 일치·빈 문의처·오프라인 캐시)
- `npm run store:shots`: 게임에서 바로 스토어 스크린샷 생성(iPhone 6.9형, Google Play)
- `npm run balance -- 48`: CPU끼리 대결로 맵·자리별 밸런스 표(왼쪽 집 승률·먼저 쏜 쪽 승률, 집과 선공을 번갈아)
- `npm run release -- patch --push`: 버전 올리고 태그 → 테스트 통과 시 TestFlight 업로드·웹 배포·스토어 스크린샷

## 친구 대결의 동작 방식

- **연결**: claude.ai 아티팩트로 열면 claude.ai `room` 기능(같은 아티팩트를 연 사람끼리의 실시간 채널)을 쓰고, 앱과 웹판에서는 우리 중계 서버(`relay/`, Cloudflare Workers + Durable Objects, 무료 요금제)를 씁니다. 중계 서버 주소를 모르는 빌드(빌드 전 개발 중)나 서버에 닿지 않을 때는 PeerJS(WebRTC 데이터 채널, 공개 PeerJS 서버로 중개)로 넘어갑니다. 중계 서버는 게임 상태를 저장하지 않고 두 폰 사이에서 전달만 하며, 연결이 끊기면 두 폰이 알아서 다시 붙습니다(5초마다 확인, 12초 무응답이면 재연결). claude.ai에서는 친구도 로그인한 상태로 이 아티팩트를 열 수 있어야 합니다(공유 메뉴에서 초대).
- **동기화**: 매 턴 쏘는 사람의 폰이 기준입니다. 발사 순간 월드 전체(대장·블록·숲·지형 파낸 기록)를 작은 스냅샷으로 만들어 양쪽 폰이 똑같이 물리 월드를 다시 세우고, 상대 폰은 같은 발사 값과 능력 발동 틱을 받아 같은 1/60초 틱으로 재생합니다. 턴이 끝나면 쏜 쪽의 결과 스냅샷으로 다시 맞추므로 기기 차이로 생기는 미세한 오차도 쌓이지 않습니다.
- **끊김**: 모든 정보가 "최신 상태" 필드로 오가므로 잠깐 끊겼다 붙으면 자동으로 따라잡고, 새로고침한 쪽(앱은 시스템이 앱을 닫았다 다시 연 쪽도)은 켜자마자 그 방으로 자동으로 돌아가 남은 쪽의 스냅샷을 받아 같은 턴부터 이어갑니다. 다른 앱을 보거나 전화를 받으러 가면 상대 화면에 '친구가 잠깐 다른 앱을 보고 있어요'가 뜹니다.
