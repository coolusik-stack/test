# 도토리 포트리스 (가제)

겨울 식량 창고를 두고 두 다람쥐 마을이 맞붙는 턴제 새총 포격 대결입니다. 포트리스식 대결 구도에 새총 물리 퍼즐의 손맛을 합친 모바일 우선 HTML5 게임으로, 빌드 과정 없이 정적 파일로 바로 실행됩니다.

- **참나무단** — 붉은다람쥐 대장 '토리', 도토리 깍지 투구
- **솔숲단** — 귀털이 긴 청설모 대장 '솔이', 솔방울 투구

## 실행

```bash
cd angry-fortress
python3 -m http.server 8080
# 휴대폰/브라우저에서 http://<내 IP>:8080 접속
```

ES 모듈을 쓰므로 `file://`로 직접 열면 동작하지 않습니다. 정적 호스팅(Cloudflare Pages, Firebase Hosting 등)에 폴더째 올리면 되고, 홈 화면에 추가하면 전체 화면 PWA로 오프라인에서도 실행됩니다.

## 플레이

- **모드**: 혼자 하기(CPU 쉬움/보통/어려움), 둘이 하기(한 폰으로 번갈아 플레이)
- **조작**: 새총 근처를 누른 채 뒤로 당겼다 놓기. 두 손가락으로 확대/축소, 한 손가락 드래그로 화면 이동, 두 번 탭하면 내 위치로 복귀
- **견과 탄환**: 날아가는 중 화면을 터치하면 능력 발동
  - 도토리(무제한): 묵직한 기본탄, 땅에 부딪히면 작은 구덩이
  - 잣(3발): 초고속 돌진, 나뭇가지에 강함
  - 땅콩(3발): 껍질이 갈라지며 알맹이 셋으로 분열, 각각 작은 폭발, 고드름에 강함
  - 밤송이(2발): 가시 대폭발로 지형과 요새를 크게 파괴
  - 호두(2발): 공중에서 멈췄다가 수직으로 쿵
- **요새 블록**: 나뭇가지, 조약돌, 나뭇잎 뭉치(잘 부서짐), 통나무(무겁고 굴러감), 벌집(깨지면 벌떼가 주변을 쏨), 버섯(통통 튕김). 요새 설계도 6종에 재료가 랜덤으로 바뀌며, 양쪽은 항상 같은 모양(좌우 대칭)
- **숲의 장애물** (매 판 랜덤, 좌우 대칭 배치)
  - 도토리나무: 수관을 맞히면 흔들리며 열매가 떨어져 아래를 때림, 견과가 느려짐. 줄기를 부수거나 발밑 땅을 파내면 통째로 쓰러져 주변을 덮침(그루터기가 남음)
  - 나무에 매달린 벌집: 나무를 맞히면 줄이 끊어져 떨어지고, 땅에 닿으면 터져 벌떼가 쏟아짐
  - 거미줄: 견과를 잠깐 붙잡았다 떨어뜨림. 붙잡힌 동안에도 능력 사용 가능
  - 민들레: 맞히면 씨앗이 날리며 바람 방향이 즉시 뒤집힘
  - 도토리 바구니: 깨면 쏜 쪽이 특수 견과 +1
- **맵**: 도토리 숲(한낮), 단풍 협곡(가을), 소나무 언덕(안개 낀 아침), 반딧불 밤숲(밤). 양 진영 뒤에 마을 나무가 서 있고, 섬 둘레는 개울
- **규칙**: 체력 100. 직격, 폭발, 떨어지는 블록, 높은 곳에서의 추락이 피해를 주고, 개울에 빠지면 즉시 패배. 매 턴 바람이 바뀌고, 18턴이 지나면 매 턴 개울물이 불어납니다.
- **데스크톱**: ←/→ 이동, 1~5 탄환 선택, Space 능력, Esc 일시정지, 마우스 휠 확대

## 구조

| 파일 | 역할 |
|---|---|
| `js/main.js` | 화면 전환, HUD, 입력 연결, 메인 루프, 타이틀 데모 |
| `js/game.js` | 한 판의 물리 월드(planck.js), 턴 상태 기계, 피해 판정, 폭발, 조준, 렌더링 |
| `js/terrain.js` | 파괴 가능한 지형(SDF 격자 → 마칭 스퀘어 → 물리 체인/Path2D) |
| `js/ai.js` | CPU: 각도×힘 탄도 탐색 후 탄환 종류별 기대 피해로 선택 |
| `js/art.js` | 다람쥐 대장, 호두 수레와 새총, 견과 탄환, 블록 벡터 드로잉 |
| `js/audio.js` | Web Audio 절차적 효과음·배경음 (외부 음원 없음) |
| `js/scene.js` · `js/fx.js` · `js/camera.js` | 숲 배경(원경·빛줄기·안개·덤불·개울), 파티클·데미지 숫자, 카메라 |
| `js/obstacles.js` | 숲 장애물(나무·거미줄·민들레·매달린 벌집·바구니) 배치와 반응, 마을 나무 |
| `js/levels.js` · `js/config.js` | 맵 테마·요새 설계도·소품, 밸런스 수치 |
| `vendor/planck.min.js` | Box2D 계열 물리 엔진 planck.js 1.4 (MIT) |
| `dev/` | 아트 미리보기, 사운드 테스트, 아이콘·공유 이미지 생성 페이지 |

밸런스는 대부분 `js/config.js` 한 곳에서 조정합니다.
