# 도토리 포트리스 (가제)

겨울 식량 창고를 두고 두 다람쥐 마을이 맞붙는 턴제 새총 포격 대결입니다. 포트리스식 대결 구도에 새총 물리 퍼즐의 손맛을 합친 모바일 우선 HTML5 게임으로, 빌드 과정 없이 정적 파일로 바로 실행됩니다.

핵심은 **친구와 각자 폰으로 1:1**입니다. 방을 만들고 4자리 코드를 알려주면 친구가 자기 폰에서 들어와 번갈아 쏘며 싸웁니다.

- **참나무단** — 주황 다람쥐 대장 '토리'
- **솔숲단** — 회색 청설모 대장 '솔이'

## 실행

```bash
cd angry-fortress
python3 -m http.server 8080
# 휴대폰/브라우저에서 http://<내 IP>:8080 접속
```

**iOS 앱(TestFlight)**: `npm install && npm run ios && npm run ios:open`으로 Xcode 프로젝트를 엽니다. 자세한 절차는 [IOS.md](IOS.md)에 있습니다. 진동(햅틱)은 iPhone 앱에서만 됩니다(iPhone 사파리는 진동 미지원).

ES 모듈을 쓰므로 `file://`로 직접 열면 동작하지 않습니다. 정적 호스팅(Cloudflare Pages, Firebase Hosting 등)에 폴더째 올리면 되고, 홈 화면에 추가하면 전체 화면 PWA로 오프라인에서도 실행됩니다.

## 플레이

- **모드**
  - **친구와 대결 (각자 폰으로 1:1)**: 방장이 '방 만들기'로 4자리 코드를 받고 '알려주기'로 공유, 친구는 '방 들어가기'에서 코드 입력. 방장이 전장·바람·턴 제한을 고르고 시작. 대결 중 이모티콘(😆😤😱👍🔥😭), 끝나면 '한 판 더'로 재대결(진 쪽이 먼저 쏨). 한쪽이 새로고침하거나 잠깐 끊겨도 타이틀의 '방 ○○○○로 돌아가기'로 이어서 할 수 있음. 링크에 `?join=코드`를 붙이면 바로 참가 화면이 열림
  - **번갈아 대결**: 폰 하나로 둘이 번갈아
  - **CPU 연습**: 쉬움/보통/어려움
- **조작**: 새총 근처를 누른 채 뒤로 당겼다 놓기. 두 손가락으로 확대/축소, 한 손가락 드래그로 화면 이동, 두 번 탭하면 내 위치로 복귀
- **견과 탄환**: 날아가는 중 화면을 터치하면 능력 발동
  - 도토리(무제한): 묵직한 기본탄, 땅에 부딪히면 작은 구덩이
  - 잣(3발): 초고속 돌진, 나뭇가지에 강함
  - 땅콩(3발): 껍질이 갈라지며 알맹이 셋으로 분열, 각각 작은 폭발, 고드름에 강함
  - 밤송이(2발): 가시 대폭발로 지형과 요새를 크게 파괴
  - 호두(2발): 공중에서 멈췄다가 수직으로 쿵
- **요새 블록**: 나뭇가지, 조약돌, 나뭇잎 뭉치(잘 부서짐), 통나무(무겁고 굴러감), 벌집(깨지면 벌떼가 주변을 쏨), 버섯(통통 튕김). 요새 설계도 6종에 재료가 랜덤으로 바뀌며, 양쪽은 항상 같은 모양(좌우 대칭)
- **숲의 장애물** (매 판 랜덤, 좌우 대칭 배치)
  - 도토리나무: 수관을 맞히면 흔들리며 열매가 떨어져 아래를 때림, 견과가 느려짐. 줄기를 부수거나 발밑 땅을 파내면 통째로 쓰러져 주변을 덮침(그루터기가 남음)
  - 나무에 매달린 벌집: 나무를 맞히면 줄이 끊어져 떨어지고, 땅에 닿으면 터져 벌떼가 쏟아짐
  - 거미줄: 견과를 잠깐 붙잡았다 떨어뜨림. 붙잡힌 동안에도 능력 사용 가능
  - 민들레: 맞히면 씨앗이 날리며 바람 방향이 즉시 뒤집힘
  - 도토리 바구니: 깨면 쏜 쪽이 특수 견과 +1
- **맵**: 도토리 숲(한낮), 단풍 협곡(가을), 소나무 언덕(안개 낀 아침), 반딧불 밤숲(밤). 양 진영 뒤에 마을 나무가 서 있고, 섬 둘레는 개울
- **규칙**: 체력 100. 직격, 폭발, 떨어지는 블록, 높은 곳에서의 추락이 피해를 주고, 개울에 빠지면 즉시 패배. 매 턴 바람이 바뀌고, 18턴이 지나면 매 턴 개울물이 불어납니다.
- **진동(햅틱)**: 새총을 당길 때 톱니처럼 딸깍, 발사 세기만큼 '퉁', 맞힌 피해만큼 '쿵'(치명타는 두 번), 맞으면 둔탁한 '퍽', 폭발·나무 쓰러짐은 울리는 진동, K.O.·승리·패배 패턴. iPhone 앱은 Core Haptics, 안드로이드 브라우저는 기본 진동
- **데스크톱**: ←/→ 이동, 1~5 탄환 선택, Space 능력, Esc 일시정지, 마우스 휠 확대

## 친구 대결의 동작 방식

- **연결**: claude.ai 아티팩트로 열면 claude.ai `room` 기능(같은 아티팩트를 연 사람끼리의 실시간 채널)을 쓰고, 그 밖의 웹 호스팅에서는 PeerJS(WebRTC 데이터 채널, 공개 PeerJS 서버로 중개)를 씁니다. claude.ai에서는 친구도 로그인한 상태로 이 아티팩트를 열 수 있어야 합니다(공유 메뉴에서 초대).
- **동기화**: 매 턴 쏘는 사람의 폰이 기준입니다. 발사 순간 월드 전체(대장·블록·숲·지형 파낸 기록)를 작은 스냅샷으로 만들어 양쪽 폰이 똑같이 물리 월드를 다시 세우고, 상대 폰은 같은 발사 값과 능력 발동 틱을 받아 같은 1/60초 틱으로 재생합니다. 턴이 끝나면 쏜 쪽의 결과 스냅샷으로 다시 맞추므로 기기 차이로 생기는 미세한 오차도 쌓이지 않습니다.
- **끊김**: 모든 정보가 "최신 상태" 필드로 오가므로 잠깐 끊겼다 붙으면 자동으로 따라잡고, 새로고침한 쪽은 남은 쪽의 스냅샷을 받아 같은 턴부터 이어갑니다.

## 구조

| 파일 | 역할 |
|---|---|
| `js/main.js` | 화면 전환, 친구 대결 로비, HUD, 입력 연결, 메인 루프, 타이틀 데모 |
| `js/game.js` | 한 판의 물리 월드(planck.js), 고정 틱 시뮬레이션, 스냅샷 저장/복원, 턴 상태 기계, 피해 판정, 폭발, 조준, 렌더링 |
| `js/haptics.js` | 진동 패턴(탭·버즈의 세기/날카로움 목록)과 iOS Core Haptics·기본 햅틱·안드로이드 진동 연결 |
| `ios/` · `capacitor.config.json` · `scripts/build-www.mjs` | Capacitor iOS 앱(가로 고정, 홈 인디케이터 숨김, 햅틱 플러그인 `GameViewController.swift`) |
| `js/online.js` | 친구 대결 세션: 방 코드, 매치 시작/재대결, 턴 스냅샷·재생 진행도·이모티콘 주고받기, 재접속 동기화 |
| `js/net.js` | 두 폰 사이 연결(claude.ai room 또는 PeerJS WebRTC)을 같은 "상태 필드" 방식으로 감쌈 |
| `js/terrain.js` | 파괴 가능한 지형(SDF 격자 → 마칭 스퀘어 → 물리 체인/Path2D) |
| `js/ai.js` | CPU: 각도×힘 탄도 탐색 후 탄환 종류별 기대 피해로 선택 |
| `js/art.js` | 단순화한 다람쥐 대장·수레·새총, 견과 탄환, 블록·나무 벡터 드로잉 |
| `js/audio.js` | Web Audio 절차적 효과음·배경음 (외부 음원 없음) |
| `js/scene.js` · `js/fx.js` · `js/camera.js` | 숲 배경(원경·빛줄기·안개·덤불·개울), 파티클·데미지 숫자, 카메라 |
| `js/obstacles.js` | 숲 장애물(나무·거미줄·민들레·매달린 벌집·바구니) 배치와 반응, 마을 나무 |
| `js/levels.js` · `js/config.js` | 맵 테마·요새 설계도·소품, 밸런스 수치 |
| `vendor/planck.min.js` | Box2D 계열 물리 엔진 planck.js 1.4 (MIT) |
| `vendor/peerjs.min.js` | WebRTC 연결 라이브러리 PeerJS 1.5 (MIT, `vendor/peerjs.LICENSE`), 친구 대결 때만 불러옴 |
| `dev/` | 아트 미리보기, 사운드 테스트, 아이콘·공유 이미지 생성 페이지 |

밸런스는 대부분 `js/config.js` 한 곳에서 조정합니다.
